# Pet Care Management&Adopt App

An organization of pets caring, non-profit app to organize animals, track their status, and facilitate user communication with pet managers.
The app also includes a special AI feature to provide users with the top 3 pet recommendations based on their search of a pet, by -> text to Image OR text to description of each pet.
Technologies we've worked with:
- Uses MVVM arhitecture.
- Firebase Firestore Database
- Python server to embedd each pet by it's image and description. Can be used locally.
